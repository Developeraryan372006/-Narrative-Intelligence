# Your Life, In Receipts

Your Life, In Receipts is an interactive personal memory archive that turns everyday moments into a visual story. Browse life chapters, explore a receipt-style ledger, discover connections between moments, view generated insights, solve mystery quests, and weave selected memories into a custom story receipt.

The experience is built with React, TypeScript, Vite, Tailwind CSS, D3, and Framer Motion.

## Run Locally

**Prerequisite:** Node.js

```bash
npm install
npm run dev
```

The app runs locally at `http://localhost:3000`.

## Build

```bash
npm run build
```


Live Preview :- https://narrativeintelligence.vercel.app/
